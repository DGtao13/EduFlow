# EduFlow v1.2.0

EduFlow v1.2.0 makes everyday timetable navigation simpler and more natural.

- Subjects now live under **Още**, leaving three primary destinations: **Разписание**, **Задачи**, and **Още**.
- Cycle configuration now lives in Schedule Setup. Current Week remains centered and easy to use in the schedule navigator.
- The timetable now supports true two-dimensional panning, including simultaneous horizontal, vertical, and diagonal movement.
- Native-style momentum works across both axes and stops immediately when you touch the timetable.
- Taps, long presses, and direct edge-drag week navigation remain available.
