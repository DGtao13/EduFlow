# EduFlow v1.0

EduFlow v1.0 is the first stable release of the local-first Android student planner.

## Highlights

- Plan A/B school timetables and dated weeks.
- Track homework and tasks with lesson-aware deadlines, checklists, and reminders.
- Keep SCHOOL and PRIVATE lessons, topics, notes, and events together.
- Create backups/exports when you choose and restore/import your data locally.

## Major features

EduFlow includes lesson blocks and cancellation handling, no-school days, recurring private lessons, configurable task and lesson reminders, Daily Overview, Quiet Hours, onboarding, and launcher shortcuts. The interface is Bulgarian-first.

## Installation

Download and install the production **APK** (`app-release.apk`) from the release. The AAB is for distribution workflows and is not the file normal Android users sideload.

## Local-first and privacy

Planner data is stored on the device. Backups and exports are created only when you initiate them; handle those files carefully because they can contain personal school information. See [Privacy](../PRIVACY.md).

## Known limitations

- The current UI is Bulgarian-first.
- Distribution is by manually installed APK rather than the Play Store.
- Delivery of reminders can be affected by Android and device-manufacturer notification restrictions.
