# EduFlow v1.3.0

## Multi-weekday recurring PRIVATE lessons

Recurring PRIVATE lessons can now repeat on multiple selected weekdays while remaining one logical recurring series. When editing a series, weekday selections can be added, removed, or replaced without creating separate recurrences.

Edits to a recurring PRIVATE lesson reconcile its future occurrences correctly, helping the schedule remain accurate as a series changes.

## Existing data upgrade

Existing recurring PRIVATE lessons are upgraded safely through the Room 11 to 12 database migration. Your existing lesson data remains part of the normal app upgrade.

## Setup wizard

Setup navigation is more consistent, with a stable Continue action area while the setup content scrolls.
