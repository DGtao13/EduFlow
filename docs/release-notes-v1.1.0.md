# EduFlow v1.1.0

EduFlow can now share individual tasks and homework between installations.

- Send a task through Android’s share sheet as an `.eduflowtask` file.
- Review every incoming task before importing it; nothing is created if you cancel.
- Match a Subject automatically when possible, or choose the receiving Subject explicitly.
- Resolve “next lesson” and “second-next lesson” deadlines using the receiving timetable.
- Warn before importing a task that was already imported.

This release does not add sharing for events or PRIVATE lessons.
