# Changelog

## EduFlow 1.1.0

- Added sharing for individual tasks and homework between EduFlow installations.
- Added `.eduflowtask` import with a review screen before anything is saved.
- Added Subject matching and an explicit Subject mapping step when needed.
- Shared lesson-relative deadlines now resolve against the receiving timetable, including the next and second-next lesson.
- Added duplicate-import protection for shared tasks.

## EduFlow 1.0.1

- Improved long-press actions for PRIVATE lessons.
- Added Edit and Delete actions when long-pressing schedule events.
- Made Start-to-End time-range entry smoother.
- Corrected project attribution to DGtao13.

## EduFlow 1.0.0

The first stable release of EduFlow, a Bulgarian-first local Android student planner.

### Schedule

- A/B timetables, dated school weeks, lesson instances, logical lesson blocks, cancellations, no-school days, and timetable events.

### Tasks

- Homework and tasks with priorities, types, checklists, exact deadlines, and lesson-aware due dates.

### Lessons

- SCHOOL lesson details, topics, notes, and one-off or recurring PRIVATE lessons with tutor and location details.

### Notifications

- Task and lesson reminders, custom lesson lead times, Daily Overview, and Quiet Hours.

### Data & backup

- Local storage, backup/archive creation, restore/import, and selected data export.

### UX

- Onboarding, setup guidance, and launcher shortcuts for common actions.
