# Contributing to EduFlow

Thanks for taking an interest in EduFlow. Bug reports, feature suggestions, and focused pull requests are welcome.

## Bug reports and suggestions

Use the GitHub issue forms after publication. Describe the problem or use case clearly, but remove personal school data, private-lesson details, and sensitive screenshots or logs.

## Development setup

EduFlow uses Kotlin, Jetpack Compose, Android Studio/Gradle, and JDK 17. Open the project in Android Studio, configure a local Android SDK, and let Gradle sync.

## Pull requests

Keep changes focused and explain why they are needed. Run relevant tests and lint before opening a PR. Include screenshots for visible UI changes, and explicitly describe any Room schema or data-migration impact.
